# PayPal Payment Integration using Java Spring Boot

This project demonstrates how to integrate the PayPal REST API with a web application using Java and Spring Boot. It allows users to make secure payments on a website, similar to UPI-based systems.

## 🔧 Tech Stack

- **Backend:** Java, Spring Boot
- **Build Tool:** Maven / Gradle
- **Payment Gateway:** PayPal REST API (Sandbox)
- **Testing Tools:** Postman
- **IDE:**Spring Tool Suit / IntelliJ IDEA
- **Version Control:** Git, SourceTree, GitHub

---

## 💡 Features

- PayPal REST API integration (sandbox mode)
- Secure payment flow with redirection and confirmation
- API endpoints for creating and executing payments
- Configurable via `.properties` or `.yaml` files
- Tested using Postman for real-world scenarios
